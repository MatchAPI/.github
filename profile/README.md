## MatchAPI

MatchAPI is an open, JSON Schema-based format for describing financial messaging APIs.

This GitHub organization hosts the public MatchAPI schema, documentation, and examples.

### Start here

- [MatchAPI Schema](https://github.com/MatchAPI/MatchAPI-Schema)
- [Core schema](https://github.com/MatchAPI/MatchAPI-Schema/blob/main/schema/matchapi-core-1.0.0.json)
- [Documentation](https://github.com/MatchAPI/MatchAPI-Schema/tree/main/docs)
- [Examples](https://github.com/MatchAPI/MatchAPI-Schema/tree/main/examples)

### Status

MatchAPI Core 1.0.0 is the initial public schema release.
